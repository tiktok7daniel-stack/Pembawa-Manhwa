# MangaVault — نظام التصميم (UI Design Spec)

> مرجع كامل لواجهة التطبيق: الهوية، الألوان، الخطوط، المكوّنات، الشاشات، الحركة، والحالات.
> مكتوب ليُنفَّذ كما هو في Jetpack Compose (أو أي واجهة ويب) بدون تخمين.

---

## 1. الفكرة الأساسية (Core Essence)

**المشكلة:** المستخدم يلصق رابط صفحة المانهوا الرئيسية، فيجد التطبيق **كل الفصول بالترتيب** (حتى المخفية في صفحة 2 و3 أو تبويبات 1-100)، ويحمّلها كلها **بضغطة واحدة** وبسرعة، في ملف CBZ داخل مجلد باسم المانهوا.

**مسار المستخدم (3 خطوات فقط):**

```
[ الصق الرابط ]  →  [ اختر الفصول ]  →  [ حمّل واقرأ ]
   Scan Series        Pick / Range         CBZ في Downloads
```

**الطابع البصري (Vibe):** "نافذة النظام" في المانهوا — واجهة داكنة كالأوبسيديان، ألواح حادة بزوايا مضيئة، توهج أزرق/سماوي، خط تقني حاد، وإحساس بأن "النظام" يفحص ويستخرج الفصول.

**ممنوعات (Zero cheap tricks):**
- لا إيموجي كأيقونات — أيقونات خطية (vector) فقط بسماكة 2px.
- لا قوالب عامة مسطّحة، ولا أزرار شكلية لا تعمل.
- لا عجلات تحميل مزعجة في القوائم — Skeleton loaders بلمعان.
- لا شاشة فارغة أو بيضاء عند الخطأ — دائماً رسالة واضحة + زر إجراء.

> ملاحظة هوية: التخطيط العام (لصق ← اختيار ← قراءة، أزرار "أول 10 / آخر 10"، قسم "كيف يعمل") مستوحى من فئة أدوات تحميل المانجا، لكن **الاسم والشعار والنصوص والشخصيات أصلية** — لا يُستخدم شعار أو تميمة أو نصوص أي موقع آخر.

## 2. الألوان (Design Tokens)

| Token | Hex | الاستخدام |
|---|---|---|
| `Bg` | `#04060B` | خلفية التطبيق (أوبسيديان) |
| `Surface` | `#0A0F1C` | أسفل الألواح |
| `SurfaceHi` | `#111A2E` | أعلى الألواح، الحقول |
| `Line` | `#1C2740` | الحدود الهادئة، المسارات الفارغة |
| `Cyan` | `#38D5FF` | اللون الأساسي، التوهج، العناصر المختارة |
| `Blue` | `#2E6BFF` | بداية تدرج الأزرار |
| `Violet` | `#7A5CFF` | ضوء جانبي خافت في الخلفية |
| `Text` | `#E9F0FF` | النص الأساسي |
| `Muted` | `#8590AA` | النص الثانوي |
| `Faint` | `#3A4560` | حدود غير مفعّلة |
| `Danger` | `#FF4D6A` | فشل / خطأ |
| `Success` | `#34F5B0` | اكتمل |
| `Warn` | `#FFB547` | صفحات ناقصة |

**التدرجات:**
- `Glow` (الأزرار والأشرطة): أفقي `Blue → Cyan`
- `GlowText` (العناوين الكبيرة): عمودي `#BFF1FF → Cyan → Blue` + ظل سماوي ضبابي (alpha 0.55, blur 28)

**الوضع:** داكن فقط (الهوية مبنية على الظلام والتوهج).

## 3. الخطوط (Typography)

| الدور | الخط | الوزن | المقاس |
|---|---|---|---|
| عنوان رئيسي (Hero) | **Rajdhani** | Bold | 52–56sp، تباعد أسطر 1.05 |
| عناوين الأقسام | Rajdhani | Bold | 22sp |
| تسميات تقنية (Labels/Tags) | Rajdhani | SemiBold | 12sp، UPPERCASE، تباعد حروف 2.2–2.4 |
| نص الأزرار | Rajdhani | Bold | 18sp، UPPERCASE، تباعد 1.8 |
| النص العادي | **Poppins** | Regular/Light | 14–16sp، تباعد أسطر 1.55 |
| العربية (كل الأدوار) | **Tajawal** | Light → Bold | نفس المقاسات |

- Rajdhani لا يحتوي حروف عربية ← في الواجهة العربية تُستبدل كل خطوط العرض بـ Tajawal.
- الروابط وأرقام الفصول تُعرض دائماً LTR حتى داخل واجهة RTL.
- كل الخطوط مرخّصة SIL Open Font License ومضمّنة في التطبيق.

| العنصر | القيمة |

| حشو اللوح الداخلي | 18dp |

## 5. المكوّنات (Components)

### 5.1 اللوح — `Panel` ("نافذة النظام")
- خلفية: تدرج عمودي `SurfaceHi @78%` → `Surface @86%` (زجاج داكن).
- حد: 1dp بتدرج من `Cyan @32%` (أعلى) إلى `Line @70%` (أسفل).
- **أقواس الزوايا:** خطوط على شكل L في الزوايا الأربع، طول 12dp، سماكة 2dp، لون `Cyan @85%`. هذه هي البصمة البصرية للتطبيق.
- نسخة `strong` (للعنصر المهم): حد `@60%` وأقواس `@100%`.
- نسخة الخطأ: نفس اللوح بلون `Danger` بدل `Cyan`.

### 5.2 الزر الأساسي — `PrimaryButton`
- خلفية `Glow` + ظل متوهج سماوي (elevation 18dp، spotColor Cyan).
- خط علوي لامع 1.5px أبيض @35% (إحساس بالحافة الزجاجية).
- أيقونة 20dp + نص UPPERCASE.
- **الضغط:** تصغير إلى 0.965 بنابض (damping 0.5, stiffness 700).
- **التحميل:** شعاع ضوء يمر أفقياً كل 1.3 ثانية + يتغير النص (مثلاً `SCANNING…`)، والزر لا يقبل ضغطاً.
- **معطّل:** شفافية 40% وبدون توهج.

### 5.3 الزر الثانوي — `GhostButton`
- خلفية `لون @6%`، حد 1dp `لون @50%`، نص وأيقونة بنفس اللون.
- يُستخدم لـ: إلغاء، إعادة محاولة الفاشل، التحقق في المتصفح.

### 5.4 زر الأيقونة — `IconBtn`
- مربع 44dp بشكل اللوح، أيقونة 20dp. (رجوع، اللغة، لصق).

### 5.5 الشريحة — `Chip`
- غير مختارة: `Surface @70%`، حد `Line`، نص `Text`.
- مختارة: `Cyan @14%`، حد `Cyan @80%`، نص `Cyan`.
- تنتقل الألوان بحركة 200ms.

### 5.6 المحدد المقسّم — `Segmented`
- حاوية بحد `Line`، و"إبهام" يتحرك بنابض (damping 0.75) تحت الخيار المختار، لونه `Cyan @14%` بحد سماوي.
- الاستخدام: صيغة التحميل، اللغة، سرعة التحميل.

### 5.7 المفتاح — `Toggle`
- مستطيل 52×28dp بزاوية 4dp، إبهام مربع 20dp.
- مفعّل: مسار `Cyan @22%` + حد سماوي + إبهام سماوي متوهج.

### 5.8 مربع الاختيار — `CheckBox`
- 22dp بزاوية 4dp؛ عند الاختيار يكبر مربع `Glow` من 0 إلى 1 بنابض مع علامة ✓ خطية بيضاء.

### 5.9 الوسم — `SystemTag`
- إطار رفيع بلون الحالة، مربع صغير **يومض** (alpha 1 ↔ 0.25 كل 0.9s)، نص UPPERCASE.
- أمثلة: `SYSTEM · MANHWA ARCHIVER`، `SCAN COMPLETE`، `EXTRACTING`، `COMPLETE`، `FAILED`.

### 5.10 الهيكل اللامع — `Skeleton`
- مستطيل `SurfaceHi @70%` يمر عليه وهج سماوي خفيف كل 1.4s. يستبدل أي spinner في القوائم.

### 5.11 شريط التقدم — `GlowBar`
- مسار `Line @60%` ارتفاع 4dp، وتعبئة `Glow` بظل سماوي، تتحرك بانسيابية 450ms.
- ألوان الحالة: مكتمل `Success`، فشل/ناقص `Danger`، جارٍ `Glow`.

### 5.12 الشعار — `Logo`
- رمز أصلي: **معيّن (Diamond) مزدوج** — إطار سماوي + معيّن داخلي بتدرج أبيض→سماوي→أزرق، مع هالة ضوء خلفه وخطّين قصيرين أعلى وأسفل (إحساس "بوابة").
- النص: `MANGA` أبيض + `VAULT` سماوي متوهج، Rajdhani Bold 21sp، تباعد 2.5.

### 5.13 الأيقونات
خطية، شبكة 24px، سماكة 2px، أطراف دائرية — كلها بنفس الوزن:

`Link` `Search` `Download` `Home` `Sliders` `Globe` `Bolt` `Layers` `Check` `Close` `Back (تنعكس في RTL)` `Archive` `Alert` `Refresh` `Trash` `Folder` `Clipboard` `ListChecks` `Activity` `Clock` `Shield` `Scan`

## 6. الخلفية والجو العام (Atmosphere)

طبقة واحدة مرسومة (Canvas) خلف كل الشاشات:
1. لون `Bg`.
2. **مصدر ضوء أزرق** في الأعلى-اليسار (radial، alpha 0.30) ينبض ببطء (0.75 ↔ 1 كل 5.2s).
3. **ضوء بنفسجي خافت** في الأسفل-اليمين (alpha 0.16).
4. شبكة خطوط 36dp بشفافية 2.8%.
5. **خط مسح (Scan line)** سماوي شفاف جداً (5%) ينزل من الأعلى للأسفل كل 9 ثوانٍ — إحساس "النظام يفحص".

كل ذلك رسم خفيف بدون صور، لا يؤثر على الأداء.

## 7. الشاشات

### 7.1 الرئيسية — Home

```
┌──────────────────────────────────────┐
│ ◇ MANGAVAULT                  [🌐]   │  شريط علوي: الشعار + زر اللغة
│                                      │
│ ■ SYSTEM · MANHWA ARCHIVER           │  SystemTag يومض
│                                      │
│ DOWNLOAD                             │  Rajdhani Bold 52sp أبيض
│ EVERY CHAPTER.                       │  GlowHeadline متوهج
│ نص تعريفي قصير بلون Muted            │
│                                      │
│ ┌─[ SERIES LINK ]──────────────────┐ │  Panel strong
│ │ (🔗) https://...           [📋]  │ │  حقل + زر لصق
│ │ (⚡) Browser mode         [▭▭]   │ │  صف المفتاح
│ │ ┌──────────────────────────────┐ │ │
│ │ │  🔍  SCAN SERIES             │ │ │  PrimaryButton
│ │ └──────────────────────────────┘ │ │
│ └──────────────────────────────────┘ │
│                                      │
│ WHAT IT DOES                         │  Label
│ ┌ Layers ┐ Every chapter, in order   │  3 ألواح ميزات حقيقية
│ ┌ Bolt   ┐ Parallel downloads        │  (أيقونة في مربع + عنوان + وصف)
│ ┌Archive ┐ One tap, one folder       │
│                                      │
│ تنبيه قانوني صغير                    │
└──────────────────────────────────────┘
        [ Home | Downloads | Settings ]   الشريط السفلي العائم
```

- الأيقونات في المخطط رمزية فقط — في التنفيذ هي أيقونات `Ic.*` الخطية.
- **أثناء الفحص (Scanning):** الزر يتحول لـ `SCANNING…` بشعاع ضوء، يظهر تحت اللوح سطر حالة يتغير كل 4 ثوانٍ (`Opening the page…` → `Reading the chapter list…` → `Still working — big series take longer…`) + **6 صفوف Skeleton** بشكل صفوف الفصول + زر `Cancel` ثانوي. لا نافذة تغطي الشاشة.
- **الخطأ:** لوح بلون `Danger` + أيقونة `Alert` + رسالة واضحة. إذا كان الموقع يطلب تحقق بشري يظهر زر `VERIFY IN BROWSER`.

### 7.2 نتيجة الفحص — Chapters

```
┌──────────────────────────────────────┐
│ [‹]  ■ SCAN COMPLETE                 │
│                                      │
│ ┌──────────────────────────────────┐ │
│ │ ┌──────┐  SOURCE-NAME            │ │  الغلاف بإطار سماوي متوهج
│ │ │ غلاف │  Series Title (Bold 24) │ │
│ │ │      │  وصف مختصر (3 أسطر)      │ │
│ │ └──────┘                          │ │
│ │ ┌ CHAPTERS ┐ ┌ SELECTED ┐         │ │  مربعا إحصاء
│ │ │   274    │ │   274    │         │ │  رقم Rajdhani متوهج
│ └──────────────────────────────────┘ │
│ [🔍 Search chapters…              ]  │
│ [From] → [To]  [APPLY]               │
│ [ALL] [FIRST 10] [LAST 10] [NONE]    │  Chips
│                                      │
│ ☑  CH. 001   عنوان الفصل            │  صفوف رفيعة
│ ☑  CH. 002   …                       │  الرقم Rajdhani سماوي بعرض ثابت 72dp
│ ...                                  │
├──────────────────────────────────────┤
│ FORMAT  [ ONE CBZ | CBZ PER CHAPTER ]│  لوح سفلي ثابت
│ وصف الصيغة المختارة                  │
│ [ ⬇  DOWNLOAD 274 CHAPTERS ]         │  PrimaryButton
└──────────────────────────────────────┘
```

- الصف المختار: حد `Cyan @50%` + خلفية `Cyan @6%` (انتقال 200ms).
- الفصول مرتبة تصاعدياً دائماً (1 → الأحدث).

### 7.3 التحميل — Progress

```
┌──────────────────────────────────────┐
│ [‹]  ■ EXTRACTING                    │  الوسم يتغير: COMPLETE / FAILED
│ ┌──────────────────────────────────┐ │
│ │ Lookism                           │ │
│ │ 47%                               │ │  Rajdhani 64sp متوهج
│ │ ━━━━━━━━━━━━━━━━━━──────────────  │ │  GlowBar 6dp
│ │ ┌ CHAPTERS ┐┌ SPEED ┐┌ TIME LEFT ┐│ │  3 مربعات إحصاء بأيقونات
│ │ │ 128/274  ││ 34 p/s││  04:12    ││ │  ListChecks / Activity / Clock
│ │ FAILED 2  (يظهر فقط عند وجود فشل) │ │
│ └──────────────────────────────────┘ │
│ CH. 127  ━━━━━━━━━━━━  DONE          │  صف لكل فصل
│ CH. 128  ━━━━━━──────  DOWNLOADING 12/30
│ CH. 129  ────────────  WAITING       │
│ CH. 130  ━━━━━━━━━━━━  FAILED        │
│          site answered 403           │  سبب الفشل بخط صغير أحمر
├──────────────────────────────────────┤
│ [ CANCEL ]                  (أثناء التحميل)
│ [ ↻ RETRY FAILED (2) ] [ 📁 OPEN DOWNLOADS ]  (بعد الانتهاء)
└──────────────────────────────────────┘
```

- النسبة = الفصول المنتهية + جزء كل فصل جارٍ (عدة فصول تعمل بالتوازي).
- السرعة = الصفحات المحمّلة ÷ الوقت المنقضي. الوقت المتبقي = الصفحات المتبقية ÷ السرعة.
- كل فصل فاشل يعرض **سببه**، وزر "إعادة محاولة الفاشل" يعيد الفاشل فقط.

### 7.4 التنزيلات — Downloads
- قائمة ألواح: مربع أيقونة `Archive` بتدرج + عنوان المانهوا + `274 chapters · 1 file` + التاريخ + المسار بخط صغير سماوي.
- الضغط يفتح تطبيق التنزيلات في النظام.
- **فارغة:** أيقونة `Folder` كبيرة داخل لوح متوهج + "Nothing downloaded yet." + زر يرجع للرئيسية.

### 7.5 الإعدادات — Settings
- **Language:** Segmented `English | العربية`.
- **Download speed:** Segmented `Balanced | Fast | Max` = 2 / 3 / 5 فصول بالتوازي، مع شرح: "اخفضها إذا بدأ موقع يرفض الطلبات".
- **Always use browser mode:** Toggle.
- **Clear cache:** زر ثانوي.
- نبذة + رقم الإصدار.

### 7.6 نافذة التحقق — Verify Sheet
- لوح من الأسفل يغطي الشاشة تقريباً، وسم `SECURITY CHECK`، عنوان "One quick check"، شرح، ثم متصفح حقيقي داخل إطار اللوح، وزر `CONTINUE`.
- المستخدم يحل فحص الموقع بنفسه — التطبيق لا يتجاوز أي حماية.

### 7.7 الشريط السفلي — Dock
- لوح عائم بعرض 280dp وارتفاع 64dp، 3 عناصر: `Home` `Download` `Sliders` + تسمية صغيرة.
- العنصر المختار: أيقونة ونص بلون `Cyan` + **خط متوهج 2dp أسفله** ينزلق بين العناصر بنابض.
- يختفي في شاشتي الفصول والتحميل (لهما شريط إجراءات خاص).

## 8. الحركة (Motion)

| الحدث | الحركة | المدة/المنحنى |
|---|---|---|
| ظهور الأقسام | تلاشي + صعود 18dp، متتابع بفارق 60ms | 450ms FastOutSlowIn |
| الانتقال بين الشاشات | تلاشي + صعود خفيف (1/14 من الارتفاع) | 380ms دخول / 200ms خروج |
| ضغط الأزرار | تصغير 0.965 | نابض (0.5 / 700) |
| الشرائح والصفوف | تغيير لون | 200ms |
| المحدد المقسّم / المفتاح / خط الـ Dock | انزلاق | نابض |
| أشرطة التقدم | امتداد | 450ms |
| زر أثناء التحميل | شعاع ضوء يعبر | 1.3s متكرر |
| الوسم | وميض المربع | 0.9s ذهاب وعودة |
| الخلفية | نبض الضوء / خط المسح | 5.2s / 9s |

القاعدة: كل حركة **150–450ms** ولها سبب (تغذية راجعة أو توجيه الانتباه). لا حركة للزينة فقط.

## 9. الحالات (States)

| الحالة | ما يظهر |
|---|---|
| تحميل قائمة | Skeleton بلمعان + سطر حالة متغير + زر إلغاء |
| فارغ | أيقونة + جملة واحدة + إجراء واضح |
| خطأ رابط | "That doesn't look like a valid link." |
| لا فصول | "No chapters found…" + نصيحة (رابط الصفحة الرئيسية / وضع المتصفح) |
| لا إنترنت | "No internet connection or the site is unreachable." |
| حماية بشرية | رسالة + زر Verify in browser |
| فصل فاشل | سبب الفشل تحت الصف + إعادة محاولة الفاشل |
| إلغاء | الوسم `CANCELLED` والملف الناقص يُحذف |

لا تظهر أبداً شاشة بيضاء/سوداء فارغة، وكل خطأ له نص مفهوم.

---

## 10. RTL والوصولية

- الواجهة العربية تقلب الاتجاه كاملاً (RTL)، وأيقونة الرجوع تنعكس تلقائياً.
- الروابط وأرقام الفصول تبقى LTR.
- تباين النص الأساسي على الخلفية أعلى من 12:1، والثانوي أعلى من 4.5:1.
- كل عناصر اللمس ≥ 44dp.
- اللون ليس المؤشر الوحيد للحالة: كل حالة لها نص (DONE / FAILED / WAITING).

---

## 11. الأداء (لماذا التطبيق سريع)

- تحليل الصفحات (HTML) على خيط خلفي — الواجهة لا تتجمد.
- **التحميل المتوازي:** عدة فصول في نفس الوقت (2/3/5 حسب الإعداد) و6 صفحات بالتوازي لكل فصل.
- الصفحات تُحفظ مؤقتاً على القرص لا في الذاكرة، ثم تُكتب في الـ CBZ بترتيب الفصول.
- يحاول الجلب العادي السريع أولاً، ولا يفتح المتصفح المدمج إلا عند الحاجة.
- في وضع المتصفح: تمرير بقفزات كبيرة بدل الزحف البطيء.
